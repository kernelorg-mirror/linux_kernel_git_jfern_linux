This is the ROM image format for type=0. It contains the BIT, BMP, EDID and executable code sections.

+----------------------------------------------------------------------------------------------------------+
|                    TYPE 0x00 (PC-AT COMPATIBLE) IMAGE STRUCTURE                                          |
+----------------------------------------------------------------------------------------------------------+
| +--------------------+                                                                                   |
| | ROM HEADER         |                                                                                   |
| | Signature: 0xAA55  |                                                                                   |
| +--------------------+                                                                                   |
| | PCI DATA STRUCTURE |                                                                                   |
| | Image Type: 0x00   | ← PC-AT Compatible                                                                |
| | + NPDE (Optional)  |                                                                                   |
| +--------------------+                                                                                   |
|                                                                                                          |
| +------------------------------------------------------------------------------------------+             |
| |                                                                                           |            |
| |                               EXECUTABLE CODE SECTIONS                                    |            |
| |                                                                                           |            |

| |                                                                                           |            |
| | +--------------------------------------------------------------------------------+        |            |
| | | INT 10h Video BIOS Routines                                                    |        |            |
| | | - Text mode services                                                           |        |            |
| | | - Graphics mode services                                                       |        |            |
| | | - VGA compatibility functions                                                  |        |            |
| | | - Called by OS or applications in legacy environments                          |        |            |

| |                                                                                           |            |

| | | Hardware Initialization Routines                                               |        |            |
| | | - Memory controller setup                                                      |        |            |
| | | - Clock configuration                                                          |        |            |
| | | - Engine initialization                                                        |        |            |
| | | - Display output configuration                                                 |        |            |

| |                                                                                           |            |
