FORMAT FOR COMPLETE ROM WITH MULTIPLE CHAINED ROM IMAGES 

+----------------------------------------------------------------------------------------------------------+
|                                           FIRST PCI ROM IMAGE                                             |
+----------------------------------------------------------------------------------------------------------+
| OFFSET: 0                                                                                                 |
+---------------------+                                                                                     |
| PCI EXPANSION       |                                                                                     |
| ROM HEADER          |                                                                                     |
|                     |                                                                                     |
| +---------------+   |                                                                                     |
| | Signature     |   | 0x55AA (2 bytes)                                                                    |
| | (0xAA55)      |   |                                                                                     |
| +---------------+   |                                                                                     |
| | PCI Data      |   | Offset to PCI Data Structure (2 bytes)                                              |
| | Structure Ptr |---+--+                                                                                  |
| +---------------+   |  |                                                                                  |
| | ...           |   |  |                                                                                  |
| +---------------+   |  |                                                                                  |
+---------------------+  |                                                                                  |
|                        v                                                                                  |
| OFFSET: pciBlck        +---------------------+                                                            |
+------------------------|                     |                                                            |
| PCI DATA STRUCTURE     | +---------------+   |                                                            |
|                        | | Signature     |   | "PCIR" (4 bytes)                                           |
|                        | | ("PCIR")      |   |                                                            |
|                        | +---------------+   |                                                            |
|                        | | Vendor ID     |   | e.g., 0x10DE for NVIDIA (2 bytes)                          |
|                        | +---------------+   |                                                            |
|                        | | Device ID     |   | Specific to the GPU model (2 bytes)                        |
|                        | +---------------+   |                                                            |
|                        | | ...           |   |                                                            |
|                        | +---------------+   |                                                            |
|                        | | Image Length  |   | Size of this image in 512-byte blocks (2 bytes)            |
|                        | +---------------+   |                                                            |
|                        | | PCI Data      |   | Size of PCI Data Structure (2 bytes)                       |
|                        | | Structure Len |   |                                                            |
|                        | +---------------+   |                                                            |
|                        | | Code Type     |   | e.g., 0x00 for PC-AT compatible image (1 byte)             |
|                        | +---------------+   |                                                            |
|                        | | Last Image    |   | 0x00 (Not the last image)                                  |
|                        | +---------------+   |                                                            |
|                        | | Class Code    |   | 3 bytes (0x03 for display controller)                      |
|                        | +---------------+   |                                                            |
|                        | | ...           |   |                                                            |
|                        | +---------------+   |                                                            |
+------------------------+---------------------+                                                            |
|                                              |                                                            |
| OPTIONAL PCI DATA EXTENSION (NPDE)           |                                                            |
| (16-byte aligned after PCI Data Structure)   |                                                            |
+----------------------+---------------------+ |                                                            |
| OFFSET: nvPciDataExtAt                     | |                                                            |
+----------------------|                     | |                                                            |
|                      | +---------------+   | |                                                            |
|                      | | Signature     |   | | NV_PCI_DATA_EXT_SIG (4 bytes) - "NPDE"                     |
|                      | +---------------+   | |                                                            |
|                      | | Revision      |   | | e.g., 0x10 or 0x11 (2 bytes)                              |
|                      | +---------------+   | |                                                            |
|                      | | Length        |   | | Size of extension structure (2 bytes)                      |
|                      | +---------------+   | |                                                            |
|                      | | Subimage Len  |   | | Same as PCIR Image Length                                  |
|                      | |               |   | | (No logical subimages here)                                |
|                      | +---------------+   | |                                                            |
|                      | | Last Image    |   | | Matches PCIR Last Image flag (0x00)                        |
|                      | +---------------+   | |                                                            |
|                      | | Flags         |   | | Special options (e.g., disable checksum)                   |
|                      | +---------------+   | |                                                            |
+----------------------+---------------------+ |                                                            |
|                                              |                                                            |
| IMAGE DATA                                   |                                                            |
+----------------------+---------------------+ |                                                            |
| OFFSET: imgDataOffset                      | |                                                            |
| (pciBlck + pciBlckLen)                     | |                                                            |
+----------------------|                     | |                                                            |
|                      |                     | |                                                            |
|                      | Actual VBIOS code   | |                                                            |
|                      | and data            | |                                                            |
|                      | (Base VBIOS Image)  | |                                                            |
|                      |                     | |                                                            |
+----------------------+---------------------+-+                                                            |
+----------------------------------------------------------------------------------------------------------+

                                           ↓
                   Next image address = current_offset + image_length * 512 bytes
                                           ↓

+----------------------------------------------------------------------------------------------------------+
|                                         SECOND PCI ROM IMAGE                                              |
+----------------------------------------------------------------------------------------------------------+
| +--------------------+     +----------------------------+     +-------------------------+                 |
| | ROM HEADER         |     | PCI DATA STRUCTURE         |     | OPTIONAL NPDE          |                 |
| | Signature: 0xAA55  |     | Signature: "PCIR"          |     | Signature: "NPDE"      |                 |
| |                    |     | Image Length: Y blocks     |     | Subimage Len: Y blocks |                 |
| +--------------------+     | Last Image: 0x00           |     | Last Image: 0x00       |                 |
|                            | Code Type: 0x03 (EFI)      |     | Flags: 0x00            |                 |
|                            +----------------------------+     +-------------------------+                 |
|                                                                                                          |
| +-----------------------------------------------------------------------------------------+              |
| |                                                                                         |              |
| |                       EFI Image Data (e.g., UEFI ROM)                                   |              |
| |                                                                                         |              |
| +-----------------------------------------------------------------------------------------+              |
+----------------------------------------------------------------------------------------------------------+

                                           ↓
                   Next image address = current_offset + image_length * 512 bytes
                                           ↓

+----------------------------------------------------------------------------------------------------------+
|                                          THIRD PCI ROM IMAGE                                              |
+----------------------------------------------------------------------------------------------------------+
| +--------------------+     +----------------------------+     +-------------------------+                 |
| | ROM HEADER         |     | PCI DATA STRUCTURE         |     | OPTIONAL NPDE          |                 |
| | Signature: 0xAA55  |     | Signature: "PCIR"          |     | Signature: "NPDE"      |                 |
| |                    |     | Image Length: Z blocks     |     | Subimage Len: Z blocks |                 |
| +--------------------+     | Last Image: 0x80 (LAST)    |     | Last Image: 0x80       |                 |
|                            | Code Type: 0x70 (NBSI)     |     | Flags: 0x00            |                 |
|                            +----------------------------+     +-------------------------+                 |
|                                                                                                          |
| +-----------------------------------------------------------------------------------------+              |
| |                                                                                         |              |
| |                   NBSI Image Data (NVIDIA BIOS Source Interface)                        |              |
| |                                                                                         |              |
| +-----------------------------------------------------------------------------------------+              |
+----------------------------------------------------------------------------------------------------------+
